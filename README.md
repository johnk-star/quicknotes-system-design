# QuickNotes System Design & API Client

This repository contains the complete System Design Architecture and REST API client implementation for QuickNotes, a high-concurrency note-taking application designed for 1,000,000 active users.

## Project Structure
- `index.html`: Interactive frontend interface for notes management.
- `api.js`: Asynchronous fetch client handling GET, POST, and DELETE requests with explicit loading, error, and empty states.
- `style.css`: Clean, responsive UI styling.
- `docs/api-design.md`: Full REST API endpoint specifications.
- `docs/data-model.md`: PostgreSQL database schema, indexing strategies, and ER diagrams.
- `docs/architecture.md`: High-availability system architecture diagram, scaling strategies, and trade-off analysis.
